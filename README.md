 🧮 Web Calculator Project
 https://github.com/580shyam/-My-calculator.git
 Features:-
  🔢 **Standard Operations:** Smoothly performs basic arithmetic including addition, subtraction, multiplication, and division.
* 📱 **Responsive Design:** Completely optimized layout that scales perfectly across mobile devices, tablets, and desktop screens.
* 🎨 **Modern UI/UX:** Clean and user-friendly interface featuring dynamic hover animations and smooth button transitions.
* ⚡ **Fast & Lightweight:** Built using vanilla technologies without heavy external frameworks, ensuring instant loading speeds.
* 🧼 **Input Correction:** Includes dedicated Clear (C) and Backspace functions to easily reset inputs or erase single digits.

## 🛠️ Technologies Used
* **HTML5** - For semantic markup and button structures.
* **CSS3** - For grid styling, modern layouts, and visual effects.
* **Git & GitHub** - For version control and free cloud hosting via GitHub Pages.

## 💻 How to Run Locally

1. Clone this repository to your local system:
   ```bash
   git clone https://github.com
   ```
2. Navigate into the project folder:
   ```bash
   cd calculator
   ```
3. Double-click the `index.html` file to open and run it
